Connexion à GitHub

La traduction tourne gratuitement sur les serveurs de GitHub. Cette page a besoin d'une clé d'accès, à créer une seule fois :

  1. Ouvre github.com/settings/personal-access-tokens/new.
  2. Donne-lui un nom (ex. « Traduction ») et choisis une expiration (ex. 1 an).
  3. Repository access → Only select repositories → choisis translation-.
  4. Permissions → Repository permissions : Actions = Read and write, Contents = Read and write.
  5. Clique sur Generate token, copie la clé et colle-la ci-dessous.

La clé reste uniquement dans ce navigateur, sur cet ordinateur.

Dépose ton MP3 ici ou clique pour choisir un fichier (MP3, M4A, WAV — 500 Mo max)
Compte environ 15 à 30 minutes pour une prêche de 45 minutes.
